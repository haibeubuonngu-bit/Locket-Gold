# 👑 BO - LocketGold Web Dashboard

Ứng dụng web tự động nâng cấp và bảo vệ **Locket Gold** dành cho thiết bị **iOS (iPhone / iPad)** với giao diện hiện đại, tối ưu tốc độ và trải nghiệm người dùng.

---

## ✨ Tính năng nổi bật

- ⚡ **Kích hoạt tự động**: Tự động phân giải tài khoản Locket và kích hoạt gói `locket_199_1m`.
- 📋 **Nút Dán 1-Chạm**: Hỗ trợ dán trực tiếp Username, ID hoặc Link mời `locket.cam/...`.
- 🔍 **Xem trước tài khoản**: Hiển thị Avatar thật, Username và UID trước khi xác nhận kích hoạt.
- 🛡️ **Anti-Revoke DNS**: Tích hợp Profile NextDNS `BO_LocketGold` (878367) và tải trực tiếp file cấu hình `.mobileconfig` để chống thu hồi Gold vĩnh viễn trên iOS.
- 🚀 **Tối ưu Vercel**: Cấu hình sẵn `vercel.json` để deploy lên Vercel Serverless Function chỉ với 1 click.

---

## 🛠️ Triển khai lên Vercel (Deploy to Vercel)

1. Đẩy code lên GitHub repository của bạn:
   ```bash
   git add .
   git commit -m "Deploy BO-LocketGold Web"
   git push origin main
   ```
2. Truy cập [Vercel Dashboard](https://vercel.com/new).
3. Chọn Repository vừa tạo và nhấn **Deploy**.

---

## 💻 Chạy cục bộ (Local Development)

1. Cài đặt dependencies:
   ```bash
   npm install
   ```
2. Khởi chạy máy chủ phát triển:
   ```bash
   npm start
   ```
3. Mở trình duyệt tại: `http://localhost:3000`
